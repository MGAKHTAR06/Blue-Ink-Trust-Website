## 🚀 Getting Started

1. **Clone the repo**
   ```bash
   git clone https://github.com/<your-username>/blue-ink-trust.git
   cd blue-ink-trust
   ```

2. **Run locally** — static site, so:
   ```bash
   npx serve .
   # or open index.html directly
   ```
